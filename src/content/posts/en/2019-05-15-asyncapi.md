At [sidion.codecamp](https://www.sidion.de/sidionLab.html) in May 2019, colleagues and I evaluated AsyncAPI, a technology I found very interesting.

It aims at the same uses that OpenAPI and Swagger offer for REST interfaces, this time for asynchronous interfaces such as JMS, MQ, MQTT, AMQP, and Kafka. An API specification of that kind is expected to provide:

- a machine-readable specification of an API
- API documentation (HTML)
- automated generation of stubs and proxies, including message validation
- automated inclusion of the API in integration tests, together with suitable test data

Whether AsyncAPI already delivers that is discussed in an article on the sidion blog: “[Asynchrone API's dokumentieren](https://www.sidion.de/lernen/sidion-labor/blog/asynchrone-api-s-dokumentieren.html)”. The title is German; the piece itself was published in German.
