Beim [sidion.codecamp](https://www.sidion.de/sidionLab.html) 2019.05 habe ich mir gemeinsam mit meinen Kollegen eine mit AsyncAPI eine sehr interessante Technologie evaluiert.

Dabei werden die gleichen Use-Cases wie es OpenAPI und Swagger für die REST Schnittstellen anbieten abenfalls auch für die asynchrone Schnittstellen wie JMS, MQ, MQTT, AMQP, Kafka, möglich. Folgendes wird von so eine API Spezifikation erwartet:
* Maschnel lesbare Spezifikation einer API
* API Dokumentation (HTML)
* Automatisierte Generierung der Stubs und Proxies mit der Nachrichtenvalidierung
* Automatisierte Einbindung der API in die Integrationstests sammt der Generierung der passenen Testdaten

Ob AsyncAPI dies bereits liefert könntest Du auf dem sidion Blog erschienenen Artikel lesen: "[Asynchrone API's dokumentieren](https://www.sidion.de/lernen/sidion-labor/blog/asynchrone-api-s-dokumentieren.html)".
